# About the BetterSearch
BetterSearch is the Website were user can search the youtube based on the the topic, length of video, category and other useful parameters.

This project should be general and scalable. As on top of this i want to add other features such as video streaming, suggesting the video based on comments. 
So i want you to design the application which will be seamless to user, following the industry standards pattern and best practices.

Core Problem: As a youtube user i just sometimes scroll the shorts or does not find any meaning video many times. And waste a lot of time watching the video which i do not intended to watch.

Current Workarounds: Current work around is to be mindful, first search the video that only you came to see.

Unique Value Proposition: To reduce the video exposure and first asking type/genera of video/lecture you want to see. So avoid distracting the user. And providing the better/mindfull video's to watch.

Target Audience Segmentation: User from the world

Platform Delivery: Website
